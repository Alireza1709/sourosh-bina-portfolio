# NITRO CEO Portfolio

پرتفولیوی فارسی و راست‌چین برای مدیرعامل نیترو ایجنسی، پیاده‌سازی‌شده با Next.js 16، App Router، React 19، TypeScript و Tailwind CSS 4.

## اجرا
```bash
npm install
npm run dev
```
سایت در `http://localhost:3000` باز می‌شود.

## معماری
- `src/app/page.tsx`: ترکیب کامپوننت‌های صفحه (Server Component)
- `src/components/sections`: هر سکشن در یک کامپوننت مستقل
- `src/components/ui`: اجزای UI مشترک
- `src/data/content.ts`: اطلاعات و نمونه‌محتوا
- `src/app/globals.css`: فقط reset، متغیرهای پایه و reduced motion؛ تمام استایل‌های سکشن‌ها داخل کلاس‌های Tailwind قرار دارند.
- `public/images`: دارایی‌های تصویری سبک WebP

## نکات تولید
- تصاویر WebP موجود از جزئیات بصری رفرنس ارسالی جدا شده‌اند تا طرح با تصویر تخت پیاده‌سازی نشود. متن‌ها، دکمه‌ها، کارت‌ها، آمار و تعاملات، عناصر واقعی React/HTML هستند. **این تصاویر تولید مستقل از صفر نیستند** و برای انتشار نهایی بهتر است با اصل دارایی‌های گرافیکی یا تصاویر اختصاصی جایگزین شوند.
- به‌دلیل در دسترس نبودن عکس واقعی مدیرعامل، تصویر معرفی فعلاً یک پرتره نمادین از مرجع است.
- نام‌ها، تاریخ‌ها، آمار، دستاوردها و پروژه‌ها در `src/data/content.ts` **نمونه/نمایشی** هستند و نباید بدون تایید منتشر شوند.
- گالری پروژه‌ها interactive و منوی موبایل باز و بسته می‌شود؛ سایر سکشن‌ها Server Component هستند.
- UI در موبایل تک‌ستونه است؛ دسکتاپ چیدمان دو‌ستونه مشابه مرجع دارد.
